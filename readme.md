Minecraft resource pack for people learning Mandarin Chinese, converts Chinese characters to Hanyu Pinyin. The language option **简体中文 (中国大陆)**, *Simplified Chinese (Mainland China)*, must be selected to display Pinyin text.

这是一个专为学习普通话的人士制作的《我的世界》（Minecraft）资源包，可将汉字转换为汉语拼音。若要显示拼音，必须选择**简体中文 (中国大陆)**语言选项。

Zhè shì yīgè zhuān wéi xuéxí pǔtōnghuà de rénshì zhìzuò de “wǒ de shìjiè”(Minecraft) zīyuán bāo, kě jiāng hànzì zhuǎnhuàn wèi hànyǔ pīnyīn. Ruò yào xiǎnshì pīnyīn, bìxū xuǎnzé Jiǎntǐ zhōngwén (zhōngguó dàlù), **简体中文 (中国大陆)**, yǔyán xuǎnxiàng.
